# Proto - A Collabrative Whiteboard


Proto is a whiteboard website with a focus on collabaration and maintaining team productivity. It can also be used
for working on personal projects, sharing boards with friends, and more. 

## Contributing

At the moment there are no plans for open contributing during the process of 
this project. Once it is in a working state and I'm satisfied with where it is, I 
will consider changes and suggestions, until then it is a stubborn process of one man 
hitting his head on the wall. 

You can contact me [Here](https://blog.noig.org/contact/), if there are any questions.
